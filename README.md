# SECTOR B: VENGEANCE

This project was made over 1 month during Hack Club's Stardance with 33 hours total, due to not having enough time to finish it before stardance ends and being very busy currently development is on hold.

# How to play?
Go to <https://alloymvp.itch.io/sector-b-vengeance>, the web version is easiest to run but not fully supported so its recommended to download the windows or linux version if possible.
